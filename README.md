# My Project

Full-stack web application structure.

## Tech Stack
- **Frontend**: React.js + JavaScript (Vite)
- **Backend**: Node.js + Express.js
- **Database**: MongoDB + Mongoose
- **Environment**: dotenv
- **Cross-Origin**: CORS
